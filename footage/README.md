# Footage

Drop real gameplay videos here (MP4, any size; they're cropped to vertical automatically).
The nightly task uses them as clip backgrounds.

Only add footage that is safe to post:
- your own WoW: Forever gameplay recordings (best: no permission needed), or
- clips a creator has said you can use. Add a matching `NAME.json` next to the video:
  `{"credit": "@creatorhandle", "permission": "where/when they said yes", "notes": "what's in it"}`

Don't add footage with copyrighted music playing (the clip maker drops the footage sound by default and
uses its own original music), leaks, test-build content or anything showing other players' private info.
